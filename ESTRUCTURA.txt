GUÍA DE USO RÁPIDA:

1. INSTALAR:
   $ npm install

2. CONFIGURAR:
   $ cp .env.example .env.local
   # Editar .env.local con credenciales Supabase

3. EJECUTAR:
   $ npm run dev
   Abre: http://localhost:3000/marcaje

4. CONSTRUIR:
   $ npm run build
   $ npm run start

5. DESPLEGAR:
   Sube a GitHub y conecta Vercel

PRÓXIMOS PASOS:

1. Descargar modelos de face-api.js
   → Coloca en public/models/

2. Configurar .env.local
   → Copia de .env.example
   → Agrega credenciales Supabase

3. npm install
   → Instala todas las dependencias

4. npm run dev
   → Inicia servidor de desarrollo

5. Crear proyecto Supabase
   → Ejecuta supabase_schema.sql

6. Registrar empleados
   → Sube datos a Supabase

7. Configurar iPads
   → URLs específicas para cada iPad

8. Desplegar a Vercel
   → Conecta repositorio GitHub
