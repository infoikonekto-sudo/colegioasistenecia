⚡ CÓMO CREAR LA BASE DE DATOS (4 PASOS SIMPLES):

1️⃣  ABRE SUPABASE
    Visita: https://supabase.com/dashboard
    Inicia sesión
    Selecciona tu proyecto

2️⃣  ABRE SQL EDITOR
    En el lado izquierdo → SQL Editor
    Click en "New Query"

3️⃣  COPIA EL CONTENIDO
    Abre: supabase_schema.sql (en VS Code)
    Selecciona todo (Ctrl+A)
    Copia (Ctrl+C)
    Pega en Supabase (Ctrl+V)

4️⃣  EJECUTA
    Click en botón azul "Run"
    Espera 10-15 segundos
    Deberías ver ✅ "Success"
