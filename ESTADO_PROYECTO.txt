🎯 PRÓXIMOS 2 PASOS (5 minutos total):
═══════════════════════════════════════════════════════════════════════════

PASO 1: CREAR BASE DE DATOS
   
   1. Abre: https://supabase.com/dashboard
   2. Selecciona tu proyecto
   3. SQL Editor → New Query
   4. Abre archivo: supabase_schema.sql
   5. Copia todo (Ctrl+A, Ctrl+C)
   6. Pega en Supabase (Ctrl+V)
   7. Click "Run"
   8. Espera 10-15 segundos
   
   Ver: CREAR_BD_SUPABASE.md para detalles completos

PASO 2: CONFIGURAR VARIABLES

   1. Abre: .env.local (en la carpeta raíz)
   2. Reemplaza:
      NEXT_PUBLIC_SUPABASE_URL=https://tu-proyecto.supabase.co
      NEXT_PUBLIC_SUPABASE_ANON_KEY=tu-clave-anon-aqui
   3. Obtén valores en: Supabase → Settings → API
   4. Guarda el archivo
   5. Reinicia servidor:
      Ctrl+C
      npm run dev

   Ver: CONFIGURACION_SUPABASE.md para detalles completos

❓ PREGUNTAS FRECUENTES:
═══════════════════════════════════════════════════════════════════════════

P: ¿Dónde está el archivo de base de datos?
R: supabase_schema.sql (en la carpeta raíz del proyecto)

P: ¿Cómo creo la base de datos?
R: Ver CREAR_BD_SUPABASE.md (4 pasos simples)

P: ¿Dónde pongo mis credenciales de Supabase?
R: En el archivo .env.local (ya existe)

P: ¿Cómo obtengo mis credenciales?
R: Supabase → Settings → API
   Copia "Project URL" y "anon key"

P: ¿Por qué no aparece la cámara?
R: Generalmente por:
   - No permitiste el permiso
   - No configuraste .env.local
   - Modelos de face-api no descargados

P: ¿Qué significa "hydration error"?
R: Ya está arreglado (eran los meta tags deprecated)

P: ¿Puedo usar esto en producción?
R: Sí, con cambios mínimos:
   - Desplegar a Vercel
   - Usar dominio personalizado
   - Configurar certificado SSL (automático en Vercel)

🆘 SOPORTE RÁPIDO:
═══════════════════════════════════════════════════════════════════════════

Si algo no funciona:

1. Revisa la consola del navegador (F12)
2. Lee el error específico
3. Busca en README_ERRORES.md
4. Verifica que ejecutaste el SQL
5. Verifica que configuraste .env.local

Errores comunes:
   - "Failed to load resource" → Falta .env.local o credenciales falsas
   - "Not found: empleados" → Falta ejecutar el SQL
   - Cámara no aparece → Permiso no permitido o modelos faltantes
   - Hydration error → Ya está arreglado, recarga la página
